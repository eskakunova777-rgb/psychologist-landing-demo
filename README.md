# Лендинг для психолога онлайн (учебный кейс)

Одностраничный сайт по учебному брифу: частный психолог, работает онлайн, хочет простой сайт с записью в Telegram. Имя, отзывы и цены условные, фото сгенерировано нейросетью.

- 5 блоков: первый экран, запросы, как проходит работа и цена, отзывы, запись
- Вёрстка под телефон в первую очередь, один файл HTML без фреймворков
- Интерактив: свет за курсором, вкладки запросов с готовым сообщением в Telegram, шкала шагов при прокрутке, отзывы со свайпом, дыхательный круг, вопросы-аккордеон, липкая кнопка записи на телефоне
- Анимации отключаются при системной настройке «уменьшить движение»
